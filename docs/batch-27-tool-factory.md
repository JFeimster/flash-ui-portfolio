# Batch 27 / Issue 94 — Tool Factory 2.0

Added a fourth working archetype: **Local intake / brief**. Configure required text, email, and select fields in the existing JSON editor. The browser validates inputs and produces a downloadable/copyable local summary. It does not submit, store, or transmit information. Existing calculator, scorecard and checklist remain supported under the existing v1 spec contract. Existing ZIP, preview, embed and handoff export paths are reused; no backend or new packaging service.
