# Asset reuse workflow

Select a project in `/sites/`, preview its source page, and open **Use This Asset** or **Inspect for Reuse**. The existing `/use-asset/` page lists included source files and external page dependencies, offers a configurable implementation brief, and provides a static ZIP when every local HTML/CSS dependency can be packaged. The ZIP contains the source files plus `README.md` and `CUSTOMIZE.md`.

`data/asset-packages.json` is generated by `node scripts/build-asset-packages.mjs`. Its `entries` map contains complete portable static packages. Its `review` map contains partial prototypes, external applications, and standalone app sources with a reason and source link. Review entries never display a download action. An iframe embed snippet shows the existing hosted preview; it is not a source export.

Use `node scripts/smoke-use-asset.mjs` with the local server on port 4173 to check the directory action, variant hub action, source list, implementation brief, missing-file state, external application state, responsive layout, and actual ZIP download.
