## Guardrails

- Do not include private client data, API keys, secrets, or protected workspace exports.
- Use public-safe examples unless the workflow is clearly internal.
- Avoid guarantees, unverifiable claims, and hidden provider bypass paths.
- Make required inputs and output formats explicit.
