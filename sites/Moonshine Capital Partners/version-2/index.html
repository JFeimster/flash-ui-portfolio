SYSTEM ARCHITECTURE & MOONSHINE PARTNER ENGINE OPS

1. Deployment Instructions

This repository is static-first and repository-friendly. Because it has no server dependencies or database requirements, it can be compiled and pushed directly to Vercel, Netlify, or GitHub Pages.

git init
git add .
git commit -m "Deploy Moonshine Partner System"
git branch -M main
git remote add origin https://github.com/moonshine-capital/partner-growth-system.git
git push -u origin main

2. How to Add a New Partner Page

Open the /data/partners.js file and add a new partner object to the main list. The site's dynamic rendering system will automatically generate routes, tracking tokens, and templates without additional builds. 

{
  partnerName: "Alex Vance",
  partnerSlug: "alex-vance",
  partnerType: "Strategic Affiliate",
  partnerReferralCode: "VANCE2026",
  partnerScorecardMode: "native"
}

3. Referral Tracking Architecture

Every call-to-action button or embedded asset intercepts and appends active tracking parameters (UTMs and partner code) using safe storage hooks in local storage.

// Local storage hooks used for tracking state localStorage.setItem('moonshine_attribution', JSON.stringify(partnerPayload));
