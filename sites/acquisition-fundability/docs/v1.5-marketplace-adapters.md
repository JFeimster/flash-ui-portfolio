# v1.5 Multi-Marketplace Import Adapters

## Supported providers

- **Empire Flippers** — automatic import through the official public Marketplace API.
- **Acquire.com** — provider URL recognition + user-supplied public listing text parser.
- **BizBuySell** — provider URL recognition + user-supplied public listing text parser.
- **Flippa** — provider URL recognition + user-supplied public listing text parser.

## Why the non-EF adapters use pasted public listing text

Acquire.com and BizBuySell publish terms restricting automated scraping/data extraction. v1.5 therefore does not fetch those listing pages server-side. The user opens a listing they are authorized to view, copies the public listing details, and pastes the text into the importer. The server-side adapter parses only that user-supplied text.

Flippa uses the same controlled user-supplied-text pattern in v1.5 so the multi-provider architecture remains predictable and does not become a general-purpose crawler.

## Normalized contract

Every adapter returns:

- `provider`
- `providerLabel`
- provider listing identifier when recoverable from the URL
- `sourceUrl`
- `affiliateUrl` when an approved referral path exists
- `extractedAt`
- normalized `fields`
- provider `context`
- source/provenance notes for every underwriting field

## Cash-flow terminology guardrail

Provider labels are preserved rather than silently converted:

- Acquire.com `TTM Profit` remains TTM Profit until the user confirms SDE vs EBITDA treatment.
- BizBuySell `Cash Flow (SDE)` maps to SDE only when the listing explicitly identifies it as such; explicit EBITDA maps to EBITDA.
- Flippa `Monthly Profit` is annualized for the calculator, but its SDE/EBITDA basis remains unresolved.

## Missing facts

The adapters do not invent management replacement cost, capex, working capital, customer concentration, books quality, or retained debt. Those remain **Needs confirmation** until the user supplies defensible diligence data.

## Core endpoint

`POST /api/import-listing`

Empire Flippers:

```json
{ "url": "https://empireflippers.com/..." }
```

Acquire.com / BizBuySell / Flippa:

```json
{
  "url": "https://marketplace.example/listing/...",
  "sourceText": "public listing text copied by the user"
}
```

The endpoint whitelists supported marketplace hosts and is not an arbitrary URL-fetch proxy.
