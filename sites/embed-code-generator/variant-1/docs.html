iFrame Parameters

Customize the behavior of the Moonshine widgets by appending query strings to the src attribute. These parameters allow for dynamic configuration without modifying the embed script.

Parameter Reference
Parameter Type Description
pid Required string Your unique Partner ID (e.g., MS-9982).
source string Tracking source for attribution (slugified).
accent hex Primary brand color. Omit the '#'.
mode enum dark, light, or glass.
lang string ISO 639-1 language code. Default: en.

JS PostMessage API

The widgets emit cross-origin events that your parent site can listen for. This is essential for triggering conversions or updating your local UI state.

// Listen for widget events
window.addEventListener('message', function(event) {
    if (event.origin !== 'https://widgets.moonshine.cap') return;
    
    const { type, payload } = event.data;
    
    if (type === 'MS_APPLICATION_SUBMITTED') {
        console.log('Lead captured:', payload.lead_id);
        // Trigger your local analytics pixel here
    }
});

CSS Custom Properties

For deep UI integration, you can override the internal CSS variables of the widget by passing a data-theme attribute or using the style parameter in the URL.

Available Variables
/* Example: Customizing typography and borders */
--ms-font-family: 'Geist', sans-serif;
--ms-border-radius: 2px;
--ms-widget-bg: transparent;
--ms-primary-glow: 0 0 20px rgba(0, 242, 255, 0.4);
