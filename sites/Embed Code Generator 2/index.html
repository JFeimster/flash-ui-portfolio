How do I track my leads?

All widgets automatically append your Partner ID and Tracking Source to every lead submitted. You can view these in your Moonshine Partner Dashboard under the "Referrals" tab.

Can I change the colors later?

Yes. If you use the JS Snippet, updates to your partner profile will reflect automatically. If using the iFrame, you will need to regenerate the code if you change the hex code.

Is it mobile responsive?

Absolutely. All widgets are designed with a fluid layout. We recommend setting the width to 100% to ensure it fits any container on your site.
