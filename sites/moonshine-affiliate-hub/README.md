# Moonshine Capital — Business Loan Affiliate / Partner Hub (Next.js SSG)

A Neo-Brutalist content hub focused on **recruiting loan brokers & affiliates** via a brutally honest pillar guide + directory + playbooks.

## Local dev
```bash
npm install
npm run dev
```

## Build (static export)
```bash
npm run build
```

Output is generated by Next in `.next` (Vercel handles it automatically). This project uses `output: "export"` for fully static deployment.

## Deploy to Vercel (GitHub → Vercel)
1. Push this repo to GitHub.
2. In Vercel: **New Project → Import Git Repository**
3. Framework preset: **Next.js**
4. Build command: `next build` (default)
5. Output: handled automatically
6. Deploy.

### Important: set your real site URL
Update `data/site.json`:
- `seo.siteUrl` → your production domain (e.g., `https://moonshinecapital.com`)

This affects canonical URLs, Open Graph URLs, `robots.txt`, and `sitemap.xml`.

## Content editing
All content is repo-local JSON in `/data`:
- `data/site.json` (brand, nav, CTAs, default SEO)
- `data/programs.json` (directory entries)
- `data/guides.json` (guide articles)
- `data/faqs.json`
- `data/testimonials.json`

## Troubleshooting
**Build fails on static export**
- Ensure no server-only features are used (no server actions, no runtime fetching, no middleware).
- Keep all data in `/data` imported at build time.

**Wrong canonical / sitemap URLs**
- Set `data/site.json -> seo.siteUrl` to the deployed domain.

**Styles not applying**
- Ensure Tailwind `content` paths include `app/**/*` and `components/**/*` (already configured).
- Restart dev server after config changes.

**Need more pages**
- Add new routes in `/app/...` and any needed JSON in `/data`.
