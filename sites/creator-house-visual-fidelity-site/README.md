# Creator House — visual fidelity build

Static, dependency-free website. The five separate photographic WebP assets are in `assets/`; the page text and controls are HTML/CSS/JavaScript, never baked into screenshots.

## Run locally

From this folder:

```powershell
python server.py
```

Open http://localhost:8000. The server resolves every direct route to the shared site shell.

Forms are local demonstrations. Submission confirms in the browser and stores a preview record in `localStorage`; it does not send an email or application to Creator House. The Intelligence signal values are simulated and labeled as such. Connect production services and reviewed legal text before public launch.

The website follows the canonical Creator House brief and copy deck under `C:\Users\jason\creator-house\docs`, with the supplied visual references governing composition.
