## 🚀 How to Deploy
This is a static build. You can deploy it anywhere in seconds.

### Option 1: Vercel (Recommended)
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this directory.
3. Profit.

### Option 2: Replit (Interactive)
1. Create a new Repl (HTML/CSS/JS or Blank).
2. Upload all files from this folder.
3. Hit Run. The included `.replit` & `replit.nix` files will configure the environment automatically.

### Option 3: Netlify / GitHub Pages
Drag and drop this folder into the Netlify dashboard, or enable GitHub Pages for this repository.
