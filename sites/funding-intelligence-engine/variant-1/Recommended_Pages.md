#### Static-1 



##### Borrower Onboarding \& Financial Integration Portal

An interactive, multi-step intake wizard where businesses securely link financial accounts (e.g., Plaid, Stripe, QuickBooks) and input core business metrics. This page feeds the structured financial profile data directly into the Funding Intelligence Engine's decision-making pipelines in real-time, showing live data-ingest status indicators.



###### Suggested Structure:

* onboarding.html
* onboarding.css
* onboarding.js
* mock-integrations.json



##### Analyst Policy Manager \& Scenario Simulator

An advanced administrative interface designed for internal underwriters and credit officers. It allows them to simulate how changing weights, risk flags, or product rules would impact active pipeline profiles, visualizes approval shifts using side-by-side comparative graphs, and exports modified 'recommendation\_weights.json' configurations.



###### Suggested Structure:

* analyst-dashboard.html
* analyst-dashboard.css
* analyst-dashboard.js
* simulation-presets.json



##### Partner Integration \& Embed API Console

A developer-oriented portal for affiliate and white-label partners to manage their API integrations. Includes credentials management, interactive endpoint documentation specifically for querying the routing engine, embeddable iframe code generators, and a webhook monitoring log to track live referral conversions.



###### Suggested Structure:

* partner-portal.html
* partner-portal.css
* partner-portal.js
* api-specs.json



##### Post-Funding Amortization \& Repayment Ledger

A dashboard for active borrowers who have successfully locked in a path. It displays active repayment streams, real-time dynamic amortization schedules, auto-debit configurations, a secure document vault for submitting monthly covenants, and an interactive 'Refinance Eligibility' countdown based on historical payment performance.



###### Suggested Structure:

* repayment-ledger.html
* repayment-ledger.css
* repayment-ledger.js
* active-loans-sample.json



##### Lender Matching Marketplace

A secure marketplace interface designed specifically for capital providers and syndication partners. It allows certified lenders to filter anonymized high-scoring borrower dossiers, place competitive terms/bids on funding paths, and review machine-generated automated underwriting summaries.



###### Suggested Structure:

* lender-marketplace.html
* lender-marketplace.css
* lender-marketplace.js
* anonymized-leads.json
