## Preview

python3 -m http.server 8080

http://localhost:8080

## Deploy
Netlify: upload the folder or connect the repository. No build command required.

Vercel: import the folder/repository. Use framework preset “Other”; no build command required.

GitHub Pages: push the files to a repository and enable Pages.

Any static host: upload all files to the same web root.

## Embed
After deployment:

<iframe
  src="https://YOUR-SITE-URL"
  title="GPT Action Architect"
  width="100%"
  height="900"
  style="border:0"
  loading="lazy">
</iframe>

Use the same iframe inside Wix, Framer, Webflow, Carrd, or another platform with an Embed/Custom Code element.
