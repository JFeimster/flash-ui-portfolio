Imports, provenance & source files

The Projects view is an index derived from imported bookmark URLs. It is not a list of 222 physical files. Your saved project edits and review decisions live separately and survive reimports.

Default Chrome auto-import scope: the direct Folder and Vibe branches under Bookmarks bar, including all nested folders and links, across available Chrome profiles. Other bookmark folders are not imported into this project registry unless you supply an export.

Importing changes the local derived registry, but preserves user edits. Each imported snapshot has its own source ID and timestamp.

Automation & enrichment controls

Background Chrome polling operates only while this local app process runs. Website and GitHub checks are explicitly started using Refresh sites + GitHub; they are not a continuously running internet crawler. Authenticated Vercel project verification and screenshots are not enabled.

How to use this installation

1. Launch Open-Asset-Command-Center.ps1 from your permanent Desktop folder. Keep its PowerShell process open while using the app at http://127.0.0.1:8765/.

2. Chrome's Folder and Vibe subtrees are checked for changes every 10 minutes while the app is open. Use Reimport Chrome to force an immediate reindex.

3. Search and filter in Projects. Click a project to edit its description, tags, approval, favorite status, and manual URL associations. Changes save immediately to user-overrides.json.

4. Use Review Queue to approve/reject candidates. Approval is editorial, not verification of the corresponding site or GitHub repository.

5. Run Refresh sites + GitHub when you need current public URL reachability and public GitHub metadata. This is a network operation but does not modify external services.

6. Use the Bookmark Explorer to select individual links or nested folders and export them. Use Imports to see which source produced the registry.

7. Back up user-overrides.json to retain your edits. No public deployment or remote storage is involved.

Do not publish this installation or its JSON files. Bookmarks can contain private URLs and conversation links.
