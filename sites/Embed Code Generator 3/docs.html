JavaScript SDK Loader

The Moonshine Loader provides a more robust way to inject widgets. It automatically handles iframe resizing and passes host-page metadata to our tracking engine.

HTML / JavaScriptindex.html
<!-- 1. Include the loader script -->
<script src="https://cdn.moonshine.capital/sdk/v2.js" async></script>

<!-- 2. Define the widget container -->
<div 
  id="ms-widget-container"
  data-ms-partner="YOUR_PARTNER_ID"
  data-ms-type="score-card"
></div>

💡 Pro-Tip

The SDK will automatically look for elements with the `data-ms-widget` attribute. You can initialize multiple widgets on a single page.

Custom Styling

Widgets are served in a Shadow DOM or Iframe, but you can pass CSS variables via the loader or URL params to match your brand's identity perfectly.

Variable Description Default
--ms-primary Main button and accent color #00f0ff
--ms-bg Widget background color #ffffff
--ms-radius Border radius for inputs/buttons 8px

Event Callbacks

Listen for specific user actions within the widget to trigger your own internal analytics or CRM updates.

JavaScriptanalytics.js
window.addEventListener('message', function(event) {
    if (event.origin !== 'https://widgets.moonshine.capital') return;
    
    const { type, payload } = event.data;

    switch(type) {
        case 'MS_WIDGET_COMPLETED':
            console.log('User finished eligibility check', payload.score);
            // Trigger Facebook Pixel or Google Analytics here
            break;
        case 'MS_APPLICATION_START':
            trackLead(payload.email);
            break;
    }
});

Security & CSP

If your site uses a strict Content Security Policy, you must whitelist our domains to ensure the widget loads correctly.

HTTP HeaderContent-Security-Policy
Content-Security-Policy: 
  frame-src https://widgets.moonshine.capital;
  script-src https://cdn.moonshine.capital;
  connect-src https://api.moonshine.capital;
