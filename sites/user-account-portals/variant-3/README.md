# Moonshine Capital — Partner Workspace

**Partner Dispatch / Punk Utility** · external channel and referral partner demonstration for `Variation 3/`.

This static fixture-only prototype is not an authenticated partner portal, CRM, revenue-share processor or lender-routing system. It separates external partners from recruited commission affiliates.

## Screens

Overview, referral submission simulation, pipeline and dossier, performance, illustrative ledger, co-branded resources, link library, communications, organization/team settings and support.

## Run

```powershell
py -m http.server 4173 --directory "Variation 3"
```

Open `http://localhost:4173/#/start`. Do not open with `file://`.

## Safety

All records are fictional aliases. No private applicant data, live writes, uploads, credentials or real payment promises exist. The page includes `noindex,nofollow`; this is not access control.
