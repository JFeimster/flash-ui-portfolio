# Moonshine Capital — Administrator / Operations Workspace

**Operations Console / Punk Utility** · internal operator demonstration for `Variation 4/`.

This static fixture-only console is not an authenticated admin portal or operational back office. Every privileged control is simulated in memory.

## Screens

Operations overview/action queue, intake triage, pipeline and deal detail, partner/affiliate oversight, metadata-only document review, communications dispatch, illustrative commission reconciliation, audit/activity log and role/settings overview.

## Run

```powershell
py -m http.server 4173 --directory "Variation 4"
```

Open `http://localhost:4173/#/start`. Do not open with `file://`.

## Safety

All applicants and organizations are fictional aliases. No real records, private documents, credentials, payment execution or live messages exist. Future operations require server-enforced RBAC and audit.
