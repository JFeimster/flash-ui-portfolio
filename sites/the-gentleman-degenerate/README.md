# The Gentleman Degenerate

A static editorial landing page for a satirical lifestyle journal about discipline, vice, money, risk, style, and self-awareness.

## Preview

Open `index.html` in a browser. The site has no build step or server dependency. The cover photograph is stored locally in `assets/lounge.jpg`.

The newsletter form is a visual prototype. It validates the email address but does not transmit or store it.
