SBA + seller note buffer (the classic closer)

Use senior debt for cost, seller note as the shock absorber. The stack that closes when docs are clean and the seller is reasonable.

Structure summary

This page shows a pattern. Your numbers will change the mix. Run the Stack Builder to generate exact amounts + fix-first plan.
  • Best for: local service deals
  • Buyer profile: first time
  • Lanes used: SBA / Bank, Seller Note

Why it closes

  • Senior debt keeps cost down.
  • Seller buffer (or equity buffer) absorbs underwriting risk.
  • Doc readiness prevents timeline death.

What breaks first

  • Unsupported add-backs → retrade or denial.
  • Working capital ignored → post-close cash pain.
  • No buffer → DSCR/concentration risk becomes fatal.
